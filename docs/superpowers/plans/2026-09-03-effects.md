# Motion and Sound Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make cards behave like cards — a real flip, a card that flies off when you swipe it, a verdict you can see — and give right, wrong and a finished test a sound. Both governed by the `visualEffects` and `audioEffects` switches that Settings already draws and that nothing currently reads.

**Architecture:** Two thin modules, `app/fx.js` and `app/audio.js`, own the decision about whether an effect happens. Screens always call them; the modules no-op when the corresponding switch is off. That single rule keeps one code path through every screen in all four on/off combinations. Sounds are synthesised from oscillators, so there are no asset files to cache.

**Tech Stack:** Hand-written ES modules, CSS transitions and keyframes, the Web Audio API. No build step, no dependencies. Vitest for the pure parts.

**Spec:** `docs/superpowers/specs/2026-09-03-french-and-effects-design.md`

**Depends on:** `docs/superpowers/plans/2026-09-03-french.md`, which must be finished and merged first. Every string this plan adds is added to both dictionaries, and `app/messages.js` reads the current language.

## Global Constraints

Copied from the spec and from `CLAUDE.md`. Every task's requirements implicitly include these.

- **No build step, no bundler, no framework, no CDN, and no animation, confetti or audio library.** ES modules loaded directly by the browser.
- **Every new module under `app/` must be added to `SHELL` in `sw.js` in the same commit, and `const CACHE = 'myquizzlet-vN'` bumped.** `test/sw.test.js` scans `app/` and `app/screens/` and fails on a missing entry.
- **New modules go flat in `app/`,** not in a subdirectory — that is what `test/sw.test.js` scans.
- **No colour literal outside a `:root` block in `app/style.css`.** `test/style.test.js` fails on any `#rgb`, `rgb()` or `hsl()` elsewhere. Confetti and flash colours are therefore custom properties defined in `:root` and in each `:root[data-theme=…]` block.
- **A screen never asks whether effects are on.** It calls the helper unconditionally; the helper decides. Any `if (settings().visualEffects)` in a screen is a defect.
- **`visualEffects` defaults to on, `audioEffects` defaults to off**, both when absent from the settings blob.
- **The OS `prefers-reduced-motion` setting overrides the app switch for travel animations**, but not for the colour flash.
- **No `AudioContext` is constructed while `audioEffects` is off.**
- **Every new user-visible string goes into both `app/i18n.en.js` and `app/i18n.fr.js`**, or `test/i18n.test.js` fails.
- Run the suite with `npm test`. Serve the app with `python3 -m http.server 8000`.

```js
import { settings } from './app.js';

// Absent means on. The switch is a way to turn motion off, not a thing you
// have to find before the app feels finished.
export function wantsMotion(blob, reducedMotion) {
  if (reducedMotion) return false;
  return blob.visualEffects !== false;
}

// The colour flash survives reduced-motion: it is feedback, not travel.
export function wantsFeedback(blob) {
  return blob.visualEffects !== false;
}

const reduced = () => window.matchMedia('(prefers-reduced-motion: reduce)').matches;

export const motionOn = () => wantsMotion(settings(), reduced());
export const feedbackOn = () => wantsFeedback(settings());
```

```js
// Every helper resolves immediately when motion is off, so a screen can await
// it unconditionally. A transition that never fires must not hang a session,
// hence the timeout alongside transitionend.
function settle(node, ms) {
  return new Promise((resolve) => {
    let done = false;
    const finish = () => {
      if (done) return;
      done = true;
      node.removeEventListener('transitionend', finish);
      resolve();
    };
    node.addEventListener('transitionend', finish);
    setTimeout(finish, ms);
  });
}

export function flip(node) {
  node.classList.toggle('flipped');
  if (!motionOn()) return Promise.resolve();
  return settle(node, 450);
}
```

### Task 3: A card that flies off, and one that slides in

**Files:**
- Modify: `app/ui.js`, `app/fx.js`, `app/style.css`, `app/screens/view.js`

**Interfaces:**
- Consumes: `motionOn` from `app/fx.js`, and the private `settle` helper added to that same file in Task 2.
- Produces:
  - `flyOut(node: Element, dir: 'left' | 'right'): Promise<void>`
  - `slideIn(node: Element, dir: 'left' | 'right'): void`

**The bug this fixes:** `swipeable`'s `end` handler calls `release()` — which animates the card back to centre — *before* calling `onRight`/`onLeft`. So a card you swiped away snaps back and then the screen redraws. It must instead be handed to `flyOut`.

- [ ] **Step 1: Give `swipeable` a drag hook and stop the springback on success**


```js

    node.style.transform = `translateX(${dx}px) rotate(${dx / 25}deg)`;
    onDrag(dx);
  };
```

and in `end`, spring back only when the swipe was abandoned:

```js
  const end = (event) => {
    if (!dragging) return;
    dragging = false;
    if (!claimed) return;
    const dx = event.clientX - startX;
    const far = Math.abs(dx) > node.offsetWidth * threshold;
    // A card that was really swiped is handed to the caller mid-flight: it
    // must not snap back to centre first.
    if (!far) return release();
    if (dx > 0) onRight(dx); else onLeft(dx);
  };
```

- [ ] **Step 3: Add `flyOut` and `slideIn` to `app/fx.js`**

```js
export function flyOut(node, dir) {
  if (!motionOn()) return Promise.resolve();
  node.classList.add('flying');
  // A frame between the transition class and the target class, or the browser
  // collapses the two and there is nothing to animate from.
  requestAnimationFrame(() => node.classList.add(dir === 'right' ? 'fly-right' : 'fly-left'));
  return settle(node, 350);
}

// The incoming card comes from the side the outgoing one left towards.
export function slideIn(node, dir) {
  if (!motionOn()) return;
  node.classList.add(dir === 'right' ? 'in-right' : 'in-left');
  node.addEventListener('animationend', () => node.classList.remove('in-right', 'in-left'), { once: true });
}

export function lift(node, on) {
  if (!motionOn()) return;
  node.classList.toggle('lifted', on);
}
```

```js
// Every sound is a few notes. Keeping them as data means the table can be
// tested and retuned without touching the player.
export const SOUNDS = {
  right:    [{ freq: 659.25, at: 0,    dur: 0.09, wave: 'triangle' },
             { freq: 880.00, at: 0.08, dur: 0.12, wave: 'triangle' }],
  wrong:    [{ freq: 160.00, at: 0,    dur: 0.14, wave: 'square' }],
  typo:     [{ freq: 493.88, at: 0,    dur: 0.12, wave: 'triangle' }],
  graduate: [{ freq: 523.25, at: 0,    dur: 0.08, wave: 'triangle' },
             { freq: 659.25, at: 0.07, dur: 0.08, wave: 'triangle' },
             { freq: 783.99, at: 0.14, dur: 0.16, wave: 'triangle' }],
  perfect:  [{ freq: 523.25, at: 0,    dur: 0.10, wave: 'triangle' },
             { freq: 659.25, at: 0.09, dur: 0.10, wave: 'triangle' },
             { freq: 783.99, at: 0.18, dur: 0.10, wave: 'triangle' },
             { freq: 1046.5, at: 0.27, dur: 0.22, wave: 'triangle' },
             { freq: 1318.5, at: 0.40, dur: 0.30, wave: 'triangle' }],
  great:    [{ freq: 523.25, at: 0,    dur: 0.10, wave: 'triangle' },
             { freq: 659.25, at: 0.09, dur: 0.10, wave: 'triangle' },
             { freq: 880.00, at: 0.18, dur: 0.26, wave: 'triangle' }],
  ok:       [{ freq: 440.00, at: 0,    dur: 0.11, wave: 'triangle' },
             { freq: 523.25, at: 0.10, dur: 0.20, wave: 'triangle' }],
  rough:    [{ freq: 392.00, at: 0,    dur: 0.12, wave: 'sine' },
             { freq: 329.63, at: 0.11, dur: 0.24, wave: 'sine' }],
};

let context = null;

// Built on the first sound, which is always inside a click or a keypress —
// browsers refuse to start an audio context anywhere else. While the switch
// is off no context is ever created at all.
function ready() {
  if (!settings().audioEffects) return null;
  if (!context) {
    const Ctor = window.AudioContext || window.webkitAudioContext;
    if (!Ctor) return null;
    context = new Ctor();
  }
  if (context.state === 'suspended') context.resume();
  return context;
}

export function play(name) {
  const audio = ready();
  const notes = SOUNDS[name];
  if (!audio || !notes) return;
  const now = audio.currentTime;
  for (const note of notes) {
    const osc = audio.createOscillator();
    const gain = audio.createGain();
    osc.type = note.wave;
    osc.frequency.value = note.freq;
    // A ramp at each end: a square wave switched on at full volume clicks.
    gain.gain.setValueAtTime(0.0001, now + note.at);
    gain.gain.exponentialRampToValueAtTime(0.18, now + note.at + 0.012);
    gain.gain.exponentialRampToValueAtTime(0.0001, now + note.at + note.dur);
    osc.connect(gain).connect(audio.destination);
    osc.start(now + note.at);
    osc.stop(now + note.at + note.dur + 0.02);
  }
}
```

```js
import { messagesEn } from './messages.en.js';
import { messagesFr } from './messages.fr.js';

const SETS = { en: messagesEn, fr: messagesFr };

// Pure. An empty session is not a triumph, so zero out of zero lands in the
// middle rather than at the top.
export function bucketFor(right, total) {
  if (total <= 0) return 'ok';
  const share = right / total;
  if (share === 1) return 'perfect';
  if (share >= 0.85) return 'great';
  if (share >= 0.6) return 'ok';
  return 'rough';
}

// The die is an argument, so the choice can be tested.
export function pick(bucket, langCode, rand = Math.random) {
  const lines = (SETS[langCode] || messagesEn)[bucket];
  return lines[Math.floor(rand() * lines.length)];
}
```

```js
// Counts to the final number, or arrives there at once when motion is off.
export function countUp(node, to, ms = 700) {
  if (!motionOn() || to === 0) { node.textContent = String(to); return; }
  const started = performance.now();
  const tick = (now) => {
    const share = Math.min(1, (now - started) / ms);
    node.textContent = String(Math.round(to * share));
    if (share < 1) requestAnimationFrame(tick);
  };
  requestAnimationFrame(tick);
}

// A conic-gradient dial. The fill is set from a custom property so the
// animation is a single transition rather than a redraw.
export function ring(pct) {
  const node = el('div', { class: 'ring' }, [el('span', { class: 'ring-num', text: '0' }), '%']);
  node.style.setProperty('--pct', motionOn() ? '0' : String(pct));
  if (motionOn()) requestAnimationFrame(() => node.style.setProperty('--pct', String(pct)));
  countUp(node.querySelector('.ring-num'), pct);
  return node;
}

export function confetti(node) {
  if (!motionOn()) return;
  const box = el('div', { class: 'confetti' });
  for (let i = 0; i < 40; i += 1) {
    const bit = el('span', { class: `bit c${(i % 4) + 1}` });
    bit.style.left = `${Math.random() * 100}%`;
    bit.style.animationDelay = `${Math.random() * 0.5}s`;
    bit.style.animationDuration = `${1.6 + Math.random() * 1.2}s`;
    bit.style.transform = `rotate(${Math.random() * 360}deg)`;
    box.append(bit);
  }
  node.append(box);
  // The whole burst removes itself; nothing else has to remember it exists.
  setTimeout(() => box.remove(), 3600);
}
```
